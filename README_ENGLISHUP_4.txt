ENGLISHUP 4.0 — projeto Android para GitHub Actions
1. Envie todos os arquivos e pastas deste ZIP para a raiz do repositório.
2. Confirme que .github/workflows/android.yml está presente.
3. Abra Actions > Android CI e aguarde assembleDebug.
4. Baixe o artefato EnglishUp-APK.
Recursos: cores royal/red, animações de entrada e toque, opção de reduzir movimentos,
níveis independentes, prova inicial, interpretação de textos com 3 perguntas,
fala via serviços do Android e progresso salvo localmente.
Limites: não inclui avaliação fonética avançada, nem fotografias comerciais licenciadas.
As ilustrações originais do pacote foram mantidas; para substituir por fotos,
será necessário obter imagens com licenças verificadas.
Projeto não compilado/testado neste ambiente.
