EnglishUp Ultimate 5.0 — BETA PARA TESTES

IMPORTANTE: Código-fonte Android, não APK pré-compilado.

1. Extraia o ZIP e envie o CONTEÚDO (incluindo a pasta .github) para a raiz do repositório GitHub.
2. Confira que o único workflow ativo é .github/workflows/android.yml, com Java 17 e Gradle 8.9.
3. Abra Actions > Android CI; se compilar, baixe o artefato EnglishUp-APK.
4. Teste com o celular: menus, texto, voz, salvamento, revisões e modo de reduzir animações.

Incluído: 500+ entradas de vocabulário, trilhas Essencial/Viagens/Trabalho/Acadêmico, textos, frases de fala, verbos, nivelamento de 30 perguntas, revisão dos erros, XP, progresso local, visual royal/red e animações.

Limitações: sem backend de IA generativa, sem análise fonética profissional, sem fotos comerciais licenciadas, sem login ou sincronização. Algumas correções de resposta digitada exigem correspondência literal e podem rejeitar sinônimos corretos.
Não foi possível compilar com Android SDK nesta sessão. É uma versão beta de testes, NÃO um lançamento pronto para Play Store.
